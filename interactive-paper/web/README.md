# Prototyp: Direct Mail mit NFC-Karte (Arbeitstitel "Mailstage")

Astro-Projekt, statische Seite. Der Name steht nur in `src/brand.ts`.

## Starten

```bash
cd interactive-paper/web
npm install
npm run dev        # Entwicklung, http://localhost:4321
npm run build      # fertige Seite nach dist/
npm run preview    # dist/ ansehen
```

## Stand

- Hero mit Karte und Handy: Tippen, Erlebnis (Video oder 3D-Produkt auf der Karte), danach Kaufen / Leistung / Termin.
- Alle Inhalte sind Beispiele. Video und 3D-Produkt sind Platzhalter aus CSS, keine echte AR.
- Echte Karten-Erkennung kommt später (z. B. MindAR). Siehe `../replica/brief.md`.
