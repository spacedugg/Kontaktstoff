# Default print profile

ISO Coated v2 300% (ECI), FOGRA39, coated offset paper, maximum ink coverage 300%.
Unmodified profile from https://eci.org/lib/exe/eci_offset_2009.zip

License source: https://sources.debian.org/data/non-free/i/icc-profiles/2.1-2/debian/copyright

This is an explicit default, not a claim about every printer or paper. Printer-specific profiles can override it in export settings. The profile is embedded in the PDF and used for actual RGB-to-CMYK conversion.
